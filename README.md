# ClearRAG

**ClearRAG: Hallucination-Resistant Retrieval-Augmented Question Answering**

## Overview
ClearRAG is an academic NLP research project exploring hallucination mitigation strategies within retrieval-augmented generation (RAG) pipelines for question answering.

## Current Status
- **Stage**: Initial Scaffolding & Literature Survey.
- Research gaps and architecture specifications are currently being analyzed prior to component implementation.

## Planned System Comparisons
The experimental framework will compare three system variants:
1. **Baseline LLM (No Retrieval)**: Standard parametric-only generation.
2. **Standard RAG Pipeline**: Conventional retrieve-then-generate pipeline.
3. **ClearRAG Pipeline**: Proposed hybrid hallucination-resistant retrieval-augmented approach.
